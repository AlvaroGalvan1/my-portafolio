# My Portfolio

Personal portfolio site, built with [Next.js](https://nextjs.org) and [Tailwind CSS](https://tailwindcss.com), deployed on [Vercel](https://vercel.com).

**Read [PURPOSE.md](PURPOSE.md) first.** It states the three things this
site is for and is the thing to decide against when something new is
proposed. [GLOSSARY.md](GLOSSARY.md) is the vocabulary (Wall, Frame, Loop,
Guardrail); [TODO.md](TODO.md) is what's left to do.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it. The page auto-updates as you edit files under `src/app`.
